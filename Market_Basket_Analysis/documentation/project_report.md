# Academic Project Report: Machine Learning-Based Market Basket Analysis

**Institution**: Birla Institute of Technology (BIT)  
**Topic**: Market Basket Analysis via Apriori and FP-Growth  

## Abstract
Empirical comparative analysis of frequent pattern mining algorithms over 1,041,000 retail transactions.
FP-Growth demonstrated 17.9x faster performance compared to Apriori without memory exhaustion at low support.
